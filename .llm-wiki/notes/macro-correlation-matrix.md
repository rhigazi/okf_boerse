# Macro Correlation Matrix

Diese Matrix fasst die Auswirkungen wichtiger US-Makro-Daten auf verschiedene Assetklassen zusammen.

| Signal | Aktien (S&P 500) | US-Dollar (DXY) | Gold | US-Anleiherenditen |
| :--- | :--- | :--- | :--- | :--- |
| **Starke Arbeitsmarktdaten** (ADP/Claims $\downarrow$) | $\downarrow$ (Zinsangst) | $\uparrow$ (Renditeattraktivität) | $\downarrow$ (Opportunitätskosten) | $\uparrow$ |
| **Schwache Arbeitsmarktdaten** (ADP/Claims $\uparrow$) | $\uparrow$ (Zinssenkungshoffnung)* | $\downarrow$ (Zinsdifferenz) | $\uparrow$ (Sicherer Hafen + USD-Schwäche) | $\downarrow$ |
| **Sinkende/stagnierende Reallöhne** | $\uparrow$ (Zinssenkungshoffnung) | $\downarrow$ (USD-Schwäche bei Rezession) | $\uparrow$ (Sicherer Hafen) | $\downarrow$ (Renditen) |
| **Stark steigende Reallöhne** | $\downarrow$ (Lohn-Preis-Spirale / Zinsangst) | $\uparrow$ (Zinserhöhung) | $\downarrow$ | $\uparrow$ |

*\*Hinweis: Bei extrem schlechten Daten kann Rezessionsangst die Aktienkurse massiv drücken.*
