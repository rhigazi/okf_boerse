# Oracle Corporation (NYSE: ORCL)

**Oracle** ist ein globaler Software- und Cloud-Infrastruktur-Konzern.

## Quartalszahlen Q1 FY2027 (Bericht vom 10. Sept 2026)
* **Umsatz:** 19,3 Milliarden USD (+30 % YoY; Konsens: 19,13 Mrd. USD).
* **Gewinn (Non-GAAP EPS):** 1,92 USD (Konsens: 1,74 USD).
* **Wachstumstreiber:** Explosives Wachstum in der Cloud-Infrastruktur (Oracle Cloud Infrastructure, OCI) um **121 % auf 7,4 Milliarden USD**, getrieben durch immensen Kapazitätsbedarf für KI-Modelle.
* **Jahresprognose:** Angehoben auf mindestens 90 Milliarden USD Umsatz und 8,10 USD bereinigtes EPS.
